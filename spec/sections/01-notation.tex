\subsection*{Conventions}

\begin{itemize}
\item Units of one family are in \emph{information order}: episode, then opening second, then cell index. ``Earlier'' and ``past'' refer to this order; a statement about $u$ that uses only earlier units is $\Gpast{u-1}$-measurable.
\item A p-value that is NaN marks an untested hypothesis. It counts in $m$ and is never rejected (treated as $+\infty$).
\item Counting comparisons of a redrawn statistic with the observed one use the relative tolerance $10^{-9}(1 + |\text{observed}|)$ in the direction that can only increase the count.
\item $\sgn(0) = 0$; the request direction $\sgn_u$ maps a zero step to $+1$.
\end{itemize}
