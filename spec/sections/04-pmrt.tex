\section{PMRT statistic}
\label{spec:pmrt}

\subsection{Assignment score}
\label{spec:pmrt.score}

\begin{equation*}
v_u = \mathrm{sgn}_u \bigl( L(W_u) - \pi_u \bigr)
\end{equation*}

The assignment score of unit u is v\_u = sgn\_u (L(W\_u) - pi\_u), with mean zero and variance pi\_u (1 - pi\_u) over the policy's draw.\claim{DEF-PMRT-SCORE}

\subsection{Weight construction}
\label{spec:pmrt.weight}

The weight w\_u is built in seven steps: target bins, receiver slots, ridge adjustment, matched filter psi = Sigma\^{}-1 mu, running score centre, Huber clip at a predicted scale, and orientation set where |z\_train| $\ge$ 2.\claim{DEF-PMRT-WEIGHT}

An earlier construction that centred the score over each episode's realised units had a rate of p $\le$ 0.05 of 0.14 for sleep hypotheses on null outcomes.\claim{EMP-ERLY}

\subsection{Statistic}
\label{spec:pmrt.stat}

\begin{equation*}
S = \sum_u v_u w_u, \qquad
\sigma^2 = \sum_u \pi_u (1 - \pi_u)\, w_u^2, \qquad
z = S / \sigma
\end{equation*}

The statistic is S = sum\_u v\_u w\_u with design variance sigma\^{}2 = sum\_u pi\_u (1 - pi\_u) w\_u\^{}2 and z = S / sigma; when sigma = 0 the code sets z = 0 and p = 1.\claim{DEF-PMRT-STAT}

\subsection{Support rule}
\label{spec:pmrt.support}

A hypothesis is tested only when it has at least 30 units, 5 accepted, 5 rejected and 3 episodes; untested hypotheses count in m and are never declared.\claim{DEF-PMRT-SUPPORT}
