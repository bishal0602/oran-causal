\abstract{In Open Radio Access Networks (O-RAN), xApps from different vendors can conflict even when each controls a
different parameter, because the parameters act on the same key performance indicators (KPIs). Resolving such
conflicts requires knowing which parameter moves which KPI, and in which direction. The logs that could reveal this
are written by controllers that react to the same network state that drives the KPIs, so relationships learned from
them are confounded. We propose randomising the conflict-mitigation layer's accept-or-reject decisions and logging
their probabilities, and introduce the predictable matched-filter randomisation test (PMRT), which redraws these
decisions to test the sharp null that a parameter family never changes a KPI. Its false discovery rate control is
asymptotic, needs no network model, and covers these nulls but not effect signs or the cells that carry an effect.
In one simulated scenario, PMRT declared nothing on placebo logs and no wrong-sign edge, with precision against a
simulated ground truth of \val{s1.map.pmrt.prec} on randomised and \val{s2.map.pmrt.prec} on confounded logs. A
referee acting on the map alone breached a radio-link-failure guard. Behind an edge-certification gate, the referee
met every guard and matched the best static rule, which never lets a pico cell sleep, and even the ground-truth map
did no better. Randomised logging thus supports valid discovery, and the decision study locates the remaining limit
of safe mitigation in the guards rather than in the map.}

\keywords{O-RAN, xApp conflict mitigation, causal discovery, randomisation inference, design-based inference, near-RT RIC}
