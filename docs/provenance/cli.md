# Provenance: the `oran-causal` CLI and the reproduce tiers

Source commit for every `CDD-ORAN@0c89106` path below is `0c89106` (`feat/v2`). The command table follows the plan's "Reproduce tiers" section and the re-run cost audit of 2026-10-15 (CDD-ORAN had no reproduce entry point: its README described the retired CDL/QACM CLI). The campaign and bridging command lines are ports; `reproduce/` is new code that calls the ported analyses, drivers and figure generators.

| New path | Source | Note |
|---|---|---|
| `packages/experiments/src/oran_causal/experiments/cli.py` | New (the `check` command is unchanged) | Parses `check`, `data fetch`, `reproduce`, `verify` and `run system`; hands `campaign`, `bridging`, `posthoc` and the launcher commands (`launch`, `colab`, `kaggle`, `vps`, `dispatch`, `fingerprint`) to their package's `main`. `run system` calls `experiments.system.stages.run_stage`; `--input KEY=PATH` repeats per key |
| `packages/experiments/src/oran_causal/experiments/campaign/__main__.py` | `CDD-ORAN@0c89106:cdd_oran/xmethod/campaign.py` (`main`: `run`, `list`, `merge`) | Same flags (`--spec`, `--part i/P`, `--out`, `--budget`, `--cost-table`, `--no-isolate`, `--registry`, `--skip-complete-from`, `--parts`, `--inputs`) and the same `list` JSON keys. Protocol texts come from `launch.bundle.bundled_texts(root)` in an unpacked bundle, else the shipped protocol; an aggregate given as `--cost-table` is converted by `campaign.cost.cost_table_from_agg`. The launch session command (`launch/commands.py`) runs this module |
| `packages/experiments/src/oran_causal/experiments/campaign/run.py` (hook only) | `CDD-ORAN@0c89106:cdd_oran/xmethod/runner.py` (`generate_dataset` call) | `Providers.dataset` (type `DatasetSource`, default `generated_dataset`) supplies a unit's dataset and truth; the bridging run sets it instead of patching `generate_dataset` |
| `packages/experiments/src/oran_causal/experiments/bridging/__main__.py` | `CDD-ORAN@0c89106:cdd_oran/xmethod/exp_b.py` (`main`: `prep`, `counts`, `list`, `run`, `merge`, `table`, `costs`, `project`) | Same subcommands and flags, minus the cloud launchers (`kaggle`, `colab`), which belong to `experiments.launch`. `costs --label` sets the factors path written into the cost document |
| `packages/experiments/src/oran_causal/experiments/reproduce/checks.py` | New | `Check` rows (`pass`, `diff`, `skip`, `error`), the markdown table, byte, text and float-tolerant JSON comparisons |
| `packages/experiments/src/oran_causal/experiments/reproduce/data.py` | New | `data fetch`: hashes every `data/manifests/<set>.sha256` entry under `data/records/<set>`. The bundle `.pyc` entries of `study1_raw`, `study1_train` and `study2_raw` are known missing and reported as such. The Zenodo download is a stub until `data/zenodo.yaml` has DOIs |
| `packages/experiments/src/oran_causal/experiments/reproduce/context.py` | New | Locations of a run (`records`, `out`, `paper`) and the guard that turns an item's exception into an error row |
| `packages/experiments/src/oran_causal/experiments/reproduce/t0.py` | The phase 5, 9 and bridging gate tests | Items `study4` (`analysis.controlled.report.run_report` with the frozen freeze commit, timestamp and CDD-ORAN input labels; bytes of `report.json`, `REPORT.md`, `csv/*` and the verdicts), `system` (Study 1 criteria and verdicts of both `v4an` runs, Study 2 discovery, Studies 2 and 3 referee evaluations with the artifact re-verification, `figures_data.json` bytes), `bridging` (tables and costs bytes), `posthoc`, `figures` |
| `packages/experiments/src/oran_causal/experiments/reproduce/t0_posthoc.py` | The posthoc gate tests | X1 to X16 from the stored records, with each gate's tolerance |
| `packages/experiments/src/oran_causal/experiments/reproduce/t0_figures.py` | The phase 10 figure gates | Runs the figures member in a child interpreter into the scratch directory. Tables: bytes against `paper/tables` (CRLF read as LF). Figures: `pdftotext -layout` text and an 80 dpi `pdftoppm` raster against `paper/figures`; skipped on a host without Arial or the PDF tools. A stored PDF that no `paper/**/*.tex` includes and the registry does not build is skipped (`fig_decision_referee.pdf`, `fig_intro_conflict.pdf`) |
| `packages/experiments/src/oran_causal/experiments/reproduce/t1.py` | Re-run cost audit, T1 | Study 4 arms `corr`, `pcorr_eq`, `pmrt_eq` on one R2 n 500 dataset per environment and `pmrt_nl_eq` on E1 (tune seed 3000000), declarations against the EVAL records of the same keys (at least 90 % agreement); Study 1 EVAL and placebo smoke episodes (120 s); PMRT at B 199 on the stored Study 1 placebo episodes (no declaration); one Study 3 referee job (`CS:PMRT`); the host fingerprint; wall time under 600 s |
| `packages/experiments/src/oran_causal/experiments/reproduce/plan.py` | Re-run cost audit, T2 and T3 | Dry run only. Prices `manifests/tiers.yaml`; Study 4 unit by unit from `specs/eval/full.json` and `artifacts/eval_cost_table.json`, cut into one part per VPS process by `campaign.shard.partition` |
| `packages/experiments/src/oran_causal/experiments/reproduce/verify.py` | Plan, same-conclusion rules | Rules per study against the frozen records; Study 4 builds the re-run's report with the frozen DEV inputs when the re-run has only merged records |
| `packages/experiments/manifests/tiers.yaml` | Re-run cost audit, sections 1 to 3 and 5 | Reference CPU-h per stage with its basis (M, P, E), the platform speed factors (VPS 2.56, Colab 1.07; `results/exp_c/calib/factors.json`) and lanes (Kaggle 4 sessions of 4 processes). T2 freezes the knockout GT of Studies 1 and 2 and drops Study 4's n 24000 units. X5/X6 has no measured sum (20 to 60, E); it is put on the Kaggle lane |
