# Provenance: analysis.system, Studies 1-3 criteria, verdicts and the report figure data

Source commit for every `CDD-ORAN@0c89106` path below is `0c89106` on `feat/v2`; `e6_dev/` stands for `CDD-ORAN@0c89106:scratchpad/e6_dev/` and `report/` for `CDD-ORAN@0c89106:reports/2026-10-02-v4-pmrt-confounded-certsafe/`.
