## Fixtures

Generated by the OLD code (`CDD-ORAN@0c89106:cdd_oran/decision/pmrt.py` with `e6_dev/pmrt_bench.py`) run under the oran-causal environment (Python 3.14.4, numpy 2.5.4) by the session-scratch script `gen_golden_old.py`: `PYTHONPATH="<CDD-ORAN>;<CDD-ORAN>/scratchpad/e6_dev" uv run python -B -W ignore gen_golden_old.py OUT.json`, then gzip with mtime 0. Data: old `crt_units.synthetic_records`, 10 training episodes (rng 11, seed0 5000) and 8 test episodes (rng 12, seed0 6000), 60 units per episode, effect 40 on `sleep`; `PmrtConfig(B=199, cv_reps=1, gb=False)`; priors from `run_integrated` on the training set (`n_prior` 10), `n_target` 8. Content: fit summaries, `rho`, test features, `run_pmrt` p / z / sign, `edges_pmrt`, `run_integrated`, `declare_all` declarations and used p-values. The new code reproduces each file bit for bit on its platform.
